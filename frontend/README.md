# Dashboard

The dashboard is a React application built with Vite. From this directory:

```bash
npm ci
npm run dev
```

Open <http://localhost:3000>. The API defaults to `http://127.0.0.1:8000`; set `VITE_API_URL` to use another backend URL.

Run the test suite with `npm test` and create a production bundle with `npm run build`. The bundle is written to `dist/` and can be served by any static web server.
